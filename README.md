# Проект Online Store*

`* проект находится в стадии разработки.`

## Описание

Проект Online Store - ядро для интернет-магазина. В дальнейшем для этого ядра возможно будет реализовать любой
интерфейс — от сайта до телеграм-бота.

## Возможности:

На данный момент созданы классы `Product` и `Category` с описанием необходимых атрибутов, для инициализации экземпляров
класса. Для класса `Category` добавлены два атрибута класса: количество категорий `category_count` и количество товаров
`product_count`.

В модуле `utils.py` реализован функционал для подгрузки данных по категориям и товарам из файла JSON. Функции читают
файл и создают объекты классов.

Созданы два класса наследников класса `Product`: «Смартфон» - `Smartphone` и «Трава газонная» - `LawnGrass`.

Класс `Smartphone` расширен атрибутами: производительность - `efficiency`, модель - `model`, объем встроенной памяти -
`memory`, цвет - `color`.

Класс `LawnGrass` расширен атрибутами: страна-производитель - `country`, срок прорастания - `germination_period`, цвет -
`color`.

Доработана функциональность сложения таким образом, чтобы можно было складывать товары только из одинаковых классов
продуктов. Новая функциональность не дает возможности сложить объекты разных классов, например смартфон и траву
газонную. При попытке сложения таких экземпляров выбрасывается ошибка `TypeError`.

Доработан метод, который добавляет продукт в категорию таким образом, чтобы не было возможности добавить вместо продукта
или его наследников любой другой объект.

## Установка и запуск:

### Установка

**1. Клонируйте репозиторий:**

```commandline
git clone https://github.com/evgenios33/online_store.git
```

**2. Установите зависимости:**

```commandline
pip install -r requirements.txt
```

### Подготовка данных

**Положите файлы c данными в папку `data/` в корне проекта:**

- `products.json`

Формат файлов должен соответствовать ожидаемой структуре (список словарей с ключами `name`, `description`, `products`).

### Запуск

```commandline
poetry run python -m main
```

## Тестирование:

Для тестирования проекта используется библиотека `pytest`. Все основные функции покрыты тестами, чтобы обеспечить
корректность работы программы.

### Запуск тестов

**Запуск тестов осуществляется командой:**

```
pytest tests/
```

### Покрытие тестами

Код проекта покрыт тестами более чем на 80%, что позволяет уверенно говорить о его надежности.

### Отчеты покрытия

HTML-отчеты по покрытию тестами можно найти в папке `htmlcov` после выполнения команды:

```
pytest --cov=src --cov-report=html
```
